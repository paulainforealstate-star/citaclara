# Prompt para Codex

Este es el prompt de partida para generar o ampliar la app con Codex:

```text
Crea una app web móvil llamada CitaClara para pedir cita en un centro de salud.
Pantallas: Inicio (próxima cita y aviso de retraso), Pedir cita (motivo + hueco, 2 pasos),
Confirmación, Mis citas (cambiar y cancelar) y un interruptor "Modo fácil" con letra grande.
Al cancelar, el hueco aparece como "liberado" para otros pacientes (lista de espera).
Recetas y Resultados son citas telefónicas. Usa datos de ejemplo, sin login real.
Separa la lógica en servicios: identidad, agenda, lista de espera y avisos.
```

## Ideas para la siguiente iteración

- Recordatorio el día antes con opción de confirmar o cancelar desde el propio aviso.
- Gestión de citas de un familiar (por ejemplo, la hija de Manuel).
- Hora estimada de entrada actualizada en tiempo real.
